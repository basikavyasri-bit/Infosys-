# Supply Chain Visibility System with Optimization Analytics

## Project Overview
The **Supply Chain Visibility System with Optimization Analytics** is a data analytics project developed using an E-commerce dataset. The project uses Microsoft Power BI to analyze supply chain operations, inventory, and warehouse efficiency through interactive dashboards and visualizations.

## Objectives
- Analyze supply chain performance using e-commerce data.
- Monitor key performance indicators (KPIs).
- Understand inventory and product-related trends.
- Evaluate warehouse efficiency.
- Identify insights that can support data-driven operational decisions.

## Tools and Technologies
- Microsoft Power BI
- E-commerce Dataset
- Data Visualization
- Data Analytics
